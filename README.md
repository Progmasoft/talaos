# TalaOS

TalaOS, the Tala Operating System, is built on [OpenTala](https://github.com/Progmasoft/opentala),
[OpenTalaLoader](https://github.com/Progmasoft/opentalaloader), [OpenCRT](https://github.com/Progmasoft/opencrt),
[TalaInit](https://github.com/Progmasoft/talainit), [TalaFS](https://github.com/Progmasoft/talafs),
[TalaPM](https://github.com/Progmasoft/talapm), [Tala Utils](https://github.com/Progmasoft/tala-utils) and
[installtala](https://github.com/Progmasoft/installtala). This repository assembles them into releases and ISO images.

TalaOS is a fixed-release, leading-edge system. A release comes every six months and an ISO image every two months.
Releases are numbered and named after places in the United Kingdom: 1 Maidstone, 2 Manchester, 3 Mersey, 4
Middlesbrough, 5 Monmouth, 6 Newcastle, 7 Newport, 8 Newry, 9 Norwich, 10 Nottingham, and on to 50 Wrexham.

Secure Boot is optional and uses keys that Progmasoft manages. Progmasoft provides no desktop environment for TalaOS.
